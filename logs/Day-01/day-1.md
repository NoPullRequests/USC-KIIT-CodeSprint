## Problem 1: Move Zeroes

**Input:**
- N = number of stones
- Array of N integers

**Output:**
Updated array with all 0s moved to the end.

**Constraints:**
- 1 ≤ N ≤ 10^5



## Problem 2: Duplicate Marks

### Input Format
- First line: Integer `N` → number of subjects
- Second line: `N` space-separated integers → marks

### Output Format
- Print `"YES"` if duplicate marks exist
- Otherwise print `"NO"`

### Example
**Input:**
N = 6

Marks = 78 85 91 78 88 95

**Output:**
YES

### Constraints
- 1 ≤ N ≤ 10^5
- 0 ≤ marks ≤ 100
